# 다국어 지원 (Internationalization) 가이드

## 개요
ModernBank 프로젝트는 한국어와 영어를 지원하는 다국어 시스템입니다.

## 백엔드 (Spring Boot) 다국어 지원

### 설정
- `MessageConfig.java`: 다국어 설정 클래스
- `messages.properties`: 기본 영어 메시지
- `messages_ko.properties`: 한국어 메시지
- 기본 로케일: 한국어 (ko)

### 사용법
```java
@Autowired
private MessageSource messageSource;

// 현재 로케일에 따른 메시지 조회
Locale locale = LocaleContextHolder.getLocale();
String message = messageSource.getMessage("account.not.found", null, locale);
```

### 메시지 키 규칙
- 도메인.동작.상태 형식 사용
- 예: `account.not.found`, `customer.created.successfully`
- 검증 메시지: `validation.` 접두사
- 비즈니스 메시지: `business.` 접두사

## 프론트엔드 (Next.js) 다국어 지원

### 설정
- `LanguageContext.tsx`: 언어 상태 관리
- `i18n.ts`: 메시지 정의 및 유틸리티
- `LanguageToggle.tsx`: 언어 전환 컴포넌트

### 사용법
```tsx
import { useLanguage } from '@/contexts/LanguageContext';

function MyComponent() {
  const { t, language, setLanguage } = useLanguage();
  
  return (
    <div>
      <h1>{t('common.title')}</h1>
      <button onClick={() => setLanguage('en')}>
        {t('common.switchToEnglish')}
      </button>
    </div>
  );
}
```

### 메시지 키 구조
- 계층적 구조 사용: `category.subcategory.key`
- 예: `customer.registration`, `account.creation.success`

## Go 서비스 다국어 지원

### 설정
- `locales/en.json`: 영어 메시지
- `locales/ko.json`: 한국어 메시지
- `utils/i18n.go`: 다국어 유틸리티

### 사용법
```go
import "modernbank_user/utils"

// Accept-Language 헤더에서 로케일 추출
locale := utils.GetLocaleFromHeader(c.GetHeader("Accept-Language"))

// 메시지 조회
message := utils.GetMessage(locale, "auth.login_successful")
```

## API 다국어 지원

### 요청 헤더
```
Accept-Language: ko-KR,ko;q=0.9,en;q=0.8
```

### 응답 예시
```json
{
  "success": true,
  "message": "계좌가 성공적으로 생성되었습니다",
  "data": { ... }
}
```

## 개발 가이드라인

### 새로운 메시지 추가 시
1. 백엔드: `messages.properties`와 `messages_ko.properties`에 추가
2. 프론트엔드: `i18n.ts`의 `messages` 객체에 추가
3. Go 서비스: `locales/en.json`과 `locales/ko.json`에 추가

### 메시지 키 네이밍 규칙
- 소문자와 점(.)으로 구성
- 명확하고 의미있는 이름 사용
- 일관된 구조 유지

### 테스트
- 각 언어별로 UI 테스트 수행
- API 응답 메시지 검증
- 언어 전환 기능 테스트

## 주의사항
- 하드코딩된 문자열 사용 금지
- 메시지 키가 없을 경우 키 자체를 반환
- 폴백 메커니즘 구현 (한국어 → 영어 → 키)
- 날짜, 숫자 형식도 로케일에 따라 처리
